# 🍕 Cozinha da Hanna — Restaurante Divertido

Jogo 2D infantil de montar pratos. A criança atende cinco clientes, anota o prato pedido, arrasta os ingredientes até o prato e ganha estrelas ao servir.

- **Jogar:** https://lrm-lgtm.github.io/cozinha-da-hanna/ (disponível quando o GitHub Pages estiver ativado)
- **Plataformas:** navegador de computador ou celular, sem instalar aplicativos.
- **Controles:** mouse ou dedo para arrastar e soltar; teclado permite usar Enter nos ingredientes como alternativa acessível.
- **Privacidade:** jogo sem login, anúncios ou coleta de dados; o recorde fica armazenado apenas no navegador.

## Publicação

O workflow `.github/workflows/pages.yml` publica a branch `main` no GitHub Pages após cada atualização. Na configuração inicial, um administrador deve abrir **Settings → Pages → Build and deployment → Source → GitHub Actions**. Depois, o workflow pode ser executado pelo menu **Actions** ou automaticamente no próximo commit da `main`.

O jogo está no arquivo `index.html` (HTML, CSS e JavaScript).
